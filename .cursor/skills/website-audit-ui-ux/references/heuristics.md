# Nielsen's 10 Usability Heuristics — Strict Review Checklist

Do one focused pass per heuristic over the rendered page.

| # | Heuristic | Strict checks |
|---|---|---|
| H1 | Visibility of system status | Loading/progress indicators; feedback on form submit; selected/active states; "where am I" orientation (breadcrumbs, current nav highlight) |
| H2 | Match with real world | Jargon-free labels; natural reading order; icons match mental models; follows real-world conventions |
| H3 | User control & freedom | Undo/back/cancel everywhere; modals dismissible; no dead ends or traps |
| H4 | Consistency & standards | Same label = same action everywhere; consistent button styles and placement; platform conventions followed |
| H5 | Error prevention | Confirmations for destructive actions; input constraints; inline validation; safe defaults; disabled states communicated |
| H6 | Recognition over recall | Options visible, not hidden; recent items surfaced; icons labeled; no cross-screen memorization required |
| H7 | Flexibility & efficiency | Keyboard shortcuts / power-user paths; search as navigation; customization without blocking novices |
| H8 | Aesthetic & minimalist | Only essential content; clear visual hierarchy; whitespace; scannable (headings, bullets, short paragraphs); progressive disclosure |
| H9 | Error recovery | Plain-language error messages; states the precise problem; suggests a fix; preserves user input; highlights the problem field |
| H10 | Help & documentation | Contextual, task-focused, concise help; reachable exactly when needed |

## Mobile pass (folded into this phase)

- Renders correctly at 360–390px width; no horizontal scroll.
- Tap targets ≥ 48px; no intrusive interstitials; text readable without zooming.
